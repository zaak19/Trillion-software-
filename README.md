# Trillion Software

Site officiel de **Trillion Software**.

## Structure du site

### 1. Applications mobiles
Les applications sont affichées verticalement :
- **Worker TSA** — disponible et illustré avec `worker-tsa.jpg`
- **Mera TSA** — disponible bientôt
- **Vault TSA** — disponible bientôt
- **Voice TSA** — disponible bientôt

### 2. Guides et informations 🔒
Deux espaces accessibles depuis leurs cartes :
- **Guides** — présentation prévue comme un catalogue de formations/guides avec affiche, nom et montant.
- **Informations** — fil d'actualité de type journal, avec textes et images, sans commentaires.

### 3. Coaching privé et livres 🔒
Deux espaces :
- **Coaching privé** — emplacement prévu pour au moins trois coachings avec fiche, description et montant.
- **Livres** — emplacement prévu pour les livres avec affiche, nom et montant.

Les cadenas sont affichés comme indicateurs de contenu protégé et pourront être reliés plus tard à un vrai système d'accès/paiement.

## Réseaux sociaux
Une section horizontale est prévue pour Instagram, Twitter/X, Facebook, TikTok et YouTube. Les liens officiels peuvent être ajoutés dans `index.html` lorsque les URL seront disponibles.

## Langues
Le sélecteur FR / EN / RU / ES / DE est fonctionnel. Le choix de langue est conservé dans le navigateur.

- `index.html` — site complet, CSS et JavaScript inclus.
- `manifest.json` — configuration PWA.
- `worker-tsa.jpg` — visuel de Worker TSA.

Le site peut être publié directement avec GitHub Pages ou un autre hébergeur statique.
